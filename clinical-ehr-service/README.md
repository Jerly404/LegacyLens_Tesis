# Clinical Electronic Health Record (EHR) Microservice

Async Python 3.11 / FastAPI microservice for patient health records, biometric telemetry ingestion, and HL7 clinical event routing.

## Technology Stack
- **Framework**: FastAPI (Async ASGI)
- **Language**: Python 3.11
- **Database ORM**: Async SQLAlchemy 2.0 + PostgreSQL / asyncpg
- **Schema Validation**: Pydantic v2
- **Container**: Docker Multi-stage Python 3.11-slim
